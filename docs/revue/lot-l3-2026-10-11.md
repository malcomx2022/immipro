## Résultat

Le parseur retirait les remarques invalides, puis l'adaptateur annonçait
`RELUE` sur la liste restante, éventuellement vide. Une incohérence sans
ses deux valeurs devenait ainsi un avis sans remarque, datable et payant.
Les deux fournisseurs présentaient le défaut : ils partagent le parseur.

Politique retenue avant code : une remarque invalide refuse l'avis entier,
même dans une liste mixte ; plus de huit remarques refuse la réponse sans
troncature. Une vraie liste vide reste un avis valide. Titres/corps et deux
sources/valeurs d'une incohérence doivent être textuels et non blancs.
Le vocabulaire commun s'applique à tous les champs affichés, y compris
les écarts. Les genres déterministes sont réservés au calcul sans IA.

Les adaptateurs utilisent le validateur pur ; la route vérifie aussi la
publication. L'usage L2 est enregistré avant refus. Aucun avis rejeté
n'est daté, aucune remarque publiée, le texte reste intact et la réservation
est rendue une seule fois. Le candidat reçoit un message `avis_mal_forme`,
distinct d'un service muet ; le motif `formulation_refusee` reste reconnu.
Aucun nouvel appel automatique pour ces causes. INV-1/2/6 ;
WF-08/RG-08.4, RG-08.8 et nouvelle RG-08.9 ; R-04 et B-07.
