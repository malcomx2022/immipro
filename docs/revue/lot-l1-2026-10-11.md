## Défauts complémentaires reproduits et corrigés

Sur le code de Claude `a978f9a`, **7 attentes échouent / 22 passent** dans
les 29 tests complémentaires : cinq erreurs SDK contiennent l'écho du

invalide contenant des identifiants est recopiée dans le diagnostic B-07.

Claude sont conservées ; aucun refus n'est rendu acceptable par les tests.

`lib/ia-transport.ts` impose toujours `redirect: manual` et vide corps et
en-têtes 3xx **avant** le parseur d'erreur SDK. `OPTIONS_DU_CLIENT` de
Claude est conservé et reçoit ce transport ainsi que `logLevel: off`.
Les causes spécifiques de Claude restent ; la valeur d'une origine
invalide n'est plus recopiée dans B-07. Le motif générique `non_configure`
parle de configuration absente/refusée, sans affirmer qu'une clé manque.
Aucun changement implicite de prestataire ou exception aux redirections.
